What to take from each

1

career-ops-hq/career-ops

76.7k starsMITNode + Markdown prompts, any agent CLI

Study closely. Closest to your idea, strongest truthfulness checks.

  • modes/_shared.md detects a role archetype against your own target-role table. Same idea as your profiles.
  • jd-skill-gap.mjs sorts JD skills into existing, supported by resume, or gap, and never adds any automatically.
  • verify-cv-facts.mjs and story-provenance-check.mjs trace every claim in a generated CV back to your own files.
  • rank-pipeline.mjs gives each job a score and a reason and never hides rows.
  • learn.mjs only changes your rules after you approve, and keeps your reply in a ledger.
2

ai-job-search-dev/ai-job-search

63.7k starsMITPython + Claude Code skills, LaTeX

Borrow the document layout, setup interview and outcome loop.

  • documents/ holds CV, LinkedIn export, projects, references and past applications, each with an outcome.md.
  • /setup builds your profile from those files or by interviewing you section by section.
  • An application-reviewer agent critiques each draft, and a grounding audit strips anything not in your sources.
  • Job portal search is Danish; swap in JobSpy.
3

srbhr/Resume-Matcher

28.8k starsApache-2.0FastAPI + Next.js + SQLite

Borrow master-resume tailoring and the plain-code ATS check.

  • One master resume, tailored copies per job. Prompts forbid adding skills, tools, employers or metrics.
  • Skill verification split that career-ops later adapted.
  • ATS score and parse check in services/ats.py and services/ats_parse/ make no LLM call.
  • An MCP server lets Claude Code drive tailoring while the app stores and renders.
4

speedyapply/JobSpy

4.5k starsMITPython library, CLI, MCP server

Use as a dependency for daily sourcing.

  • scrape_jobs(site_name=[...], search_term=..., hours_old=24) returns a DataFrame.
  • Run one search per profile each morning to build the pool for the top 10.
  • LinkedIn rate-limits quickly, so keep result counts low or add proxies.
5

DaKheera47/job-ops

4.1k starsCommons ClauseTypeScript, Docker

Read for product shape. Don't fork: the license forbids selling it.

  • Search, score 0-100, tailor, export and track in one self-hosted UI, with no auto-apply on purpose.
  • Pluggable extractors per job board and Gmail-based status updates.

Recommendation

Don't fork any of them wholesale. Build a small pipeline in resume_pipeline and borrow: JobSpy for sourcing, career-ops' archetypes and fact gates for profiles and truthfulness, Resume-Matcher's tailoring rules, and ai-job-search's document layout and outcome loop. The explicit decision log is new.

Also looked at

reactive-resume (44.7k) and rendercv (17.8k) build and render resumes but don't match jobs; either could render our CVs. ApplyPilot (1.7k) applies automatically, which conflicts with approving each role yourself.
